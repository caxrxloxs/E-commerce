# Astro E-commerce

* Primero se aprendio a usar Astro en [pagina oficial](https://docs.astro.build/es/tutoria).
* Se creo Blog de ejemplo para aprender la estructura de carpetas y archivos [Proyecto en GitHub](https://github.com/caxrxloxs/blogTutorialAstro).

```text
/
├── components/
    └── Header.svg
    └── Footer.svg
    └── Card.svg
├── src/
│   ├── layouts/
│   │   └── BaseLayout.astro
│   └── pages/
│       └── index.astro
└── package.json
```

* Se crearon componentes reutilizables y un layout base 
* Se creo carpeta con css globales
* Se usaron Props para traer valores de un achivo .astro a otro y asi poder usar los Card con la API.
* Se agrego en etiqueta de image atributo alt para Accesibilidad web.
* Se controlo sus versiones con git en [GitHub](https://github.com/caxrxloxs/E-commerce).
